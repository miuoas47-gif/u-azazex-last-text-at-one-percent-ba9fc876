A phone on its last 1% of battery gets exactly one text before it dies. This program writes that text: short, honest, and funny enough to be worth the final percent. One line, no setup, no second draft — the battery would not allow one.

## Run it

```sh
python3 main.py
```

With no arguments it writes the last text to `entry.txt` inside the directory named by `MAKEFUN_OUTPUT_DIR` (or `/output`), then prints it. Every run writes the exact same bytes.
